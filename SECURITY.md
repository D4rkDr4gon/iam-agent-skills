# Security policy

## Reporting

If you find a security issue in this repository, report it privately through GitHub **Security → Report a vulnerability**. Do not open a public issue. Examples: a script that could execute untrusted input, or leaked sensitive data in a skill.

## Scope

These skills give guidance to AI agents. They contain no product code from any vendor. Vulnerabilities in One Identity, OpenText, Wazuh or other products must be reported to those vendors.

## Leaked data

If you notice customer or personal data in this repository, report it the same way. It will be removed, and history rewritten if necessary.
